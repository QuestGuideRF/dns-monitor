# DNS Monitor - Мониторинг DNS-запросов в реальном времени

![DNS Monitor](https://img.shields.io/badge/DNS-Monitor-blue)
![Python](https://img.shields.io/badge/Python-3.7+-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

Система мониторинга DNS-запросов в реальном времени с веб-интерфейсом, блокировкой рекламы и детальной статистикой.

## 🌟 Возможности

- **DNS прокси-сервер** - перехват и логирование всех DNS-запросов
- **Блокировка рекламы** - автоматическая блокировка рекламных доменов
- **Веб-интерфейс** - современный и удобный интерфейс для мониторинга
- **Статистика в реальном времени** - количество запросов, блокировок, клиентов
- **Фильтры и поиск** - поиск по домену, IP клиента, статусу блокировки
- **Графики** - визуализация активности DNS-запросов за 24 часа
- **Топ доменов и клиентов** - анализ наиболее активных доменов и устройств
- **База данных** - хранение всех запросов с индексами для быстрого поиска

## 📋 Требования

- Python 3.7 или выше
- Права администратора (для использования порта 53)
- Браузер с поддержкой современных веб-технологий

## 🚀 Установка

1. Клонируйте или скачайте этот репозиторий:
```bash
cd dns-monitor
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. (Опционально) Отредактируйте `blocklist.txt` для настройки блокировки доменов

## 📖 Использование

### Запуск DNS-сервера

**Windows (с правами администратора):**
```powershell
# Для тестирования на порту 5353 (без прав администратора)
python dns_server.py 5353

# Для продакшн использования на порту 53 (требуются права администратора)
python dns_server.py 53
```

**Linux/Mac:**
```bash
# Для тестирования
python3 dns_server.py 5353

# Для продакшн использования
sudo python3 dns_server.py 53
```

Параметры:
- Первый аргумент: порт (по умолчанию 5353 для тестирования)
- Второй аргумент: upstream DNS сервер (по умолчанию 8.8.8.8)

Пример:
```bash
python dns_server.py 5353 1.1.1.1
```

### Запуск веб-интерфейса

В отдельном терминале:
```bash
python web_server.py
```

Откройте браузер и перейдите по адресу: **http://localhost:5000**

### Настройка системы для использования DNS-сервера

#### Windows:
1. Откройте "Центр управления сетями и общим доступом"
2. Выберите активное подключение → "Свойства"
3. Выберите "IP версии 4 (TCP/IPv4)" → "Свойства"
4. Установите "Использовать следующие адреса DNS-серверов"
5. Предпочитаемый DNS: `127.0.0.1` (если используете порт 53)

#### Linux:
```bash
# Отредактируйте /etc/resolv.conf
sudo nano /etc/resolv.conf

# Добавьте в начало файла:
nameserver 127.0.0.1
```

#### macOS:
```bash
# Системные настройки → Сеть → Дополнительно → DNS
# Добавьте 127.0.0.1 в качестве DNS-сервера
```

## 🔧 Конфигурация

### Настройка блокировки

Отредактируйте `blocklist.txt`:
```txt
# Добавьте домены для блокировки (один на строку)
ads.example.com
tracker.example.com
malware.net
```

Блокируются:
- Точные совпадения доменов
- Все поддомены (например, `ads.google.com` заблокирует и `sub.ads.google.com`)

### Изменение upstream DNS

Измените DNS-сервер для пересылки запросов:
```bash
python dns_server.py 5353 1.1.1.1  # Cloudflare DNS
python dns_server.py 5353 8.8.8.8  # Google DNS
python dns_server.py 5353 208.67.222.222  # OpenDNS
```

### Настройка веб-сервера

В `web_server.py` можно изменить:
- Порт: `app.run(port=5000)`
- Хост: `app.run(host='0.0.0.0')` для доступа из сети

## 🛡️ Безопасность

- DNS-сервер поддерживает только UDP запросы (стандартный DNS протокол)
- Веб-интерфейс использует CORS для защиты от XSS
- База данных использует параметризованные запросы для защиты от SQL инъекций
- Все входные данные экранируются на клиенте

## 🐛 Устранение проблем

### Ошибка "Permission denied" на порту 53
Запустите скрипт с правами администратора или используйте непривилегированный порт (5353).

### DNS-запросы не логируются
1. Проверьте, что DNS-сервер запущен
2. Убедитесь, что система использует ваш DNS-сервер
3. Проверьте firewall/антивирус

### Веб-интерфейс не открывается
1. Убедитесь, что Flask-сервер запущен
2. Проверьте, что порт 5000 не занят
3. Откройте `http://localhost:5000` в браузере

### База данных не создается
Проверьте права на запись в текущей директории.

## 🔄 Обновление блок-листа

Можно использовать популярные блок-листы:
- [Steven Black's hosts](https://github.com/StevenBlack/hosts)
- [AdAway](https://adaway.org/)
- [Pi-hole blocklists](https://github.com/pi-hole/pi-hole)

Конвертируйте формат hosts в список доменов:
```bash
# Из hosts файла извлечь только домены
cat hosts | grep "^0.0.0.0" | awk '{print $2}' > blocklist.txt
```
